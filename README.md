# Mission Readiness Advisor

AI-powered decision-support tool that estimates launch-delay risk by combining surface weather, space weather, and historical launch data — with plain-language explanations for mission planners.

## Problem Statement

Rocket launch decisions depend on dozens of fast-changing signals — surface weather conditions, space weather (solar activity, geomagnetic storms), and vehicle/site history — each governed by strict Launch Commit Criteria. Professional-grade forecasting tools exist (e.g. 45th Weather Squadron, Tomorrow.io), but they are closed systems built for large agencies and commercial operators. Small satellite teams, university CubeSat programs, and smaller launch providers rarely have access to an integrated, explainable risk assessment tool — they're left manually cross-referencing multiple data sources under time pressure.

## Solution Description

**Mission Readiness Advisor** is a dashboard that takes a launch site, target date, and vehicle class as input, and returns:

- A composite **delay-risk score** (0–100%) with a GO / CAUTION / NO-GO status
- A **breakdown by risk factor**: surface weather, space weather, and historical launch-site performance
- A **plain-language mission brief** explaining *why* the score is what it is, generated by an LLM from the underlying data — not just raw numbers

The goal is not to replace expert judgment, but to compress multiple data sources into a single, explainable first read — the kind of tool a small team without a dedicated meteorology staff could actually use.

## AI Approach and Architecture

```
[User Input: site, date, vehicle class]
        │
        ▼
[Data Ingestion / ETL Pipeline]
   ├─ Surface weather (Open-Meteo API)
   ├─ Space weather — solar wind, Bz, Bt, Dst index, flare data (NASA/NOAA SWPC)
   └─ Historical launch outcomes (Launch Library 2 API)
        │
        ▼
[Feature Engineering + Rule Engine]
   Launch Commit Criteria encoded as explicit thresholds
   (e.g. wind speed, lightning probability, cloud cover limits)
        │
        ▼
[ML Layer — Space Weather Risk Classifier]
   Trained on ~6.7M historical space-weather observations.
   Predicts elevated geomagnetic/flare risk within a forward
   time window (forecast horizon, not same-timestep correlation)
   using only leading indicators (Bz, Bt, solar wind speed/density) —
   Dst/flare values at the prediction time are excluded to avoid
   label leakage.
        │
        ▼
[LLM Explanation Layer]
   Combines rule-engine output + ML risk score into a natural-language
   mission brief (IBM watsonx / Granite)
        │
        ▼
[Dashboard UI]
   Risk gauge, factor breakdown, constraint log, AI mission brief
```

### Model Notes (honesty over vanity metrics)

Two modeling approaches were tested for the space-weather component:

- **Same-timestep classification** (using Dst/flare-derived features to explain current anomaly flags) achieved near-perfect PR-AUC (~0.999) — but this reflects that the inputs are physically definitional to the output, not a genuine early-warning signal. This result is *not* used as a forecasting claim.
- **Forward-shifted forecasting** (predicting storm risk N hours ahead using only leading solar wind indicators, with same-timestep Dst/flare values excluded) is the version actually used in the product, at a reduced but honest PR-AUC. Given the weak-but-above-random signal, the model output is treated as a **risk ranking / alerting aid for human review**, not an automated go/no-go decision — thresholds are tuned against the PR curve rather than a fixed 0.5 cutoff.

This distinction matters: a tool that quietly reports 99.9% accuracy from a leaky setup would be misleading to mission planners. We chose to report the harder, honest number instead.

## Tech Stack

- **Data**: NASA/NOAA space weather datasets, Open-Meteo API, Launch Library 2 API
- **ML**: scikit-learn (gradient-boosted classifier, time-series cross-validation)
- **LLM Explanation**: IBM watsonx / Granite
- **Backend**: Python (FastAPI)
- **Frontend**: HTML/CSS/JS dashboard
- **Development Tool**: IBM Bob (primary)
